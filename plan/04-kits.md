# 04 — Kits (producto estrella)

Los kits aumentan el ticket promedio, reducen la comparación producto por producto y permiten crear productos nuevos (#101, #102…) **sin comprar más inventario**. EPY ya vende kits Starter/Arduino/ESP32, así que el mercado conoce el concepto: la diferenciación está en **proyecto + contenido + experiencia de compra**.

Margen bruto objetivo de kits: **40–60%** (SUPUESTO).

| Kit | BOM (lista de materiales) | Cliente | Dificultad | Proyecto guía |
|-----|---------------------------|---------|-----------|---------------|
| **Kit IoT ESP32** | ESP32 + DHT11/DHT22 + HC-SR04 + protoboard + jumpers + cable USB-C + guía | Estudiante / maker | Inicial–media | Estación de temperatura y humedad por Wi-Fi |
| **Kit Smart Home** | ESP32 + PIR + relé 5V + sensor de puerta + fuente 5V + protoboard + jumpers | Profesional / hogar | Media | Luz automática y alerta de puerta |
| **Kit Robótica** | Arduino + L298N + 2 motores TT + 2 ruedas + chasis 2WD + sensores + jumpers | Estudiante / colegio | Media | Carrito evasor de obstáculos |
| **Kit Estudiante** | Arduino + protoboard + LEDs + resistencias + jumpers + sensores | Estudiante principiante | Inicial | 10 prácticas básicas |
| **Kit Riego** (derivado) | ESP32 + relé + sensor humedad suelo + mini bomba + fuente | Hogar / agro | Media | Riego automático |
| **Kit Bomba Wi-Fi** (derivado) | ESP32 + relé 5V + fuente 5V + sensor de nivel | Técnico | Media | "Necesito controlar una bomba de agua por Wi-Fi" |

## Para cada kit falta definir (tarea `ZV-012`)
- Costo total (suma de BOM con costo real).
- Precio de venta y margen.
- Empaque y manual/guía (PDF + video corto).
- Potencial de venta (medir con preventa por WhatsApp).

## Escalera de valor
`Componentes → Kit → Proyecto → Servicio → Solución empresarial`
